# Plan: `Ata.object` makro DSL + `api` makrosu + ince OpenAPI katmanı

## 0. Genel bakış

Hedef sözdizimi:

```crystal
TaskSchema = Ata.object do
  string :title, min: 1
  int :priority, gt: 0, optional: true
end

api :post, "/tasks",
  body: TaskSchema,
  summary: "Create a new task",
  security: ["bearer_auth"],
  responses: {201 => TaskSchema, 400 => ErrorSchema, 404 => ErrorSchema} do
  task = create_task(body.title)     # ← compile-time, body.title
  env.status(201).json(task)
end
```

Üç büyük parça:
1. **`Ata.object` → makro** — gizli struct üretir; `body.title`'ı mümkün kılan tek yol (compile-time tip bilgisi).
2. **`api` makrosu** — validasyon + parse + handler splice; `body`/`query` NamedTuple.
3. **`OpenApi` ince katmanı** — `api` makrosundan gelen kayıtlarla OpenAPI 3.1 spec üretir.

**Sorumluluk sınırı:** `Ata.object` makrosu + `AtaValidator` core = `ata-validator-crystal` paketinde. `api` makrosu + `env.status/text/json` helper + `OpenApi` = `yozgat-crystal` uygulamasında.

## 2. Kritik mimari kararlar (baştan netleştir)

1. **`Ata.object` makro olur, `body.title` sadece o zaman çalışır.** Runtime `Schema` sınıfı tip taşımaz; NamedTuple tipi ancak compile-time kod üretimiyle gelir. (Ask mode'da netleştirdik — tek yol bu.)
2. **Makro, bloktan AST okur** (`macro object(&block)`), blok gövdesini **çalıştırmaz** — ayrıştırır. Yani `with builder yield` runtime sorunu **tamamen ortadan kalkar** (blok runtime'da hiç çalışmaz).
3. **Şema JSON'u derleme zamanında string'e çevirmek yerine, runtime'da `JSON.build` ile üret** (memoize). Sebep: compile-time JSON escaping çetrefilli (pattern `\d+` vs JSON escape). Runtime `JSON.build` hem güvenli hem zaten yazdığın Builder koduna benzer.
4. **OpenAPI 3.1 hedefle.** `exclusiveMinimum: 0` (draft-06/07) OpenAPI 3.0'da geçersiz, 3.1'de geçerli. `schema_json`'u olduğu gibi gömersin, dönüşüm yok.
5. **`status` makroda yok, varsayılan yok.** Handler `env.status(code).json/text(...)` ile karar verir.
6. **Query v1: string/pattern yaklaşımı.** Query'ler string; coerce magic yok (aşağıda detay).

## 3. Adım 1 — `ata-validator-crystal`: `Ata.object`'i makroya çevir

### 3.1 Makro iskeleti

`src/dsl.cr` tamamen değişir:

```crystal
require "json"
require "./validator"

module Ata
  module Schemas
    # üretilen struct'lar buraya girer (Ata::Schemas::Schema<line>)
  end

  # Ata.object artık makro. Bloktaki çağrıları (Call düğümleri) ayrıştırır,
  # her alan için: schema fragment + from_json parçası üretir.
  macro object(&block)
    {% fields = [] of String %}
    {% exprs = block.body.is_a?(Expressions) ? block.body.expressions : [block.body] %}

    {% for expr in exprs %}
      {% if expr.is_a?(Call) && (expr.name == "string" || expr.name == "int" ||
                                  expr.name == "float" || expr.name == "bool" ||
                                  expr.name == "any"   || expr.name == "array" ||
                                  expr.name == "object") %}
        {% kind = expr.name %}
        {% name = expr.args[0] %}
        {% named = expr.named_args %}
        {% optional = named && named.find { |na| na.name == "optional" } %}
        # → her field için burada "field defs" topla (bkz. 3.2)
      {% end %}
    {% end %}

    struct Ata::Schemas::Schema{{ block.line_number }}_{{ block.column_number }}
      @@schema_json : String?

      def self.schema_json : String
        @@schema_json ||= String.build do |io|
          JSON.build(io) do |j|
            j.object do
              j.field "type", "object"
              j.field "properties" do
                j.object do
                  # ── her alan için üretilen satırlar ──
                  j.field "title" do
                    j.object do
                      j.field "type", "string"
                      j.field "minLength", 1
                    end
                  end
                  # ──────────────────────────────────────
                end
              end
              j.field "required", ["title", "priority"] unless required.empty?
            end
          end
        end
      end

      def self.validate(json : String) : AtaValidator::ValidationResult
        AtaValidator::Validator.new(schema_json).validate(json)
      end

      def self.valid?(json : String) : Bool
        validate(json).valid
      end

      def self.from_json(raw : String)
        json = JSON.parse(raw)
        {
          title: json["title"].as_s,
          priority: json["priority"]?.try(&.as_i),
        }
      end
    end

    Ata::Schemas::Schema{{ block.line_number }}_{{ block.column_number }}
  end
end
```

**Anahtar noktalar:**

- **Blok normalizasyonu:** `block.body.is_a?(Expressions) ? block.body.expressions : [block.body]` — blok gövdesi 1 ifadeyse `Expressions` değil doğrudan `Call` düğümü olabilir. (Resmi workaround — kaynak: crystal#5258.)
- **Unique isim:** `block.line_number + "_" + block.column_number` — aynı satırda iki `Ata.object` olursa çakışmayı önler. (Aynı satır + sütun çakışması pratikte imkânsız.)
- **`Ata::Schemas` boş module açıkça tanımlanmalı**, yoksa "can't reopen module" tarzı sorunlar çıkabilir (aslında açık tanımlama güvenli).
- Makro sonunda **struct'ın tipini döndür** (`Ata::Schemas::Schema...`), böylece `TaskSchema = Ata.object do ... end` bir tip alias'ı olur.

### 3.2 Her alan tipi için üretilecek kod tablosu

`Call` düğümünden okuyacakların: `expr.name` (kind), `expr.args[0]` (alan adı), `expr.named_args` (kısıtlar). `named_args` bir `NamedTupleLiteral`; her elemanın `.name` ve `.value`'su var. `optional` bulmak: `named.find { |na| na.name == "optional" }`.

| DSL çağrısı | Schema fragment (üretilen `j.field` bloğu) | `from_json` parçası | NamedTuple tipi |
|---|---|---|---|
| `string :title, min: 1` | `j.field "title" do j.object do j.field "type","string"; j.field "minLength",1 end end` | `json["title"].as_s` | `String` |
| `int :priority, gt: 0, optional: true` | `"type":"integer"`, `"exclusiveMinimum":0` | `json["priority"]?.try(&.as_i)` | `Int32?` |
| `float :x, gte: 0` | `"type":"number"`, `"minimum":0` | `json["x"].as_f` | `Float64` |
| `bool :active` | `"type":"boolean"` | `json["active"].as_bool` | `Bool` |
| `any :payload` | (boş object `{}`) | `json["payload"]` | `JSON::Any` |
| `array :tags, of: :string, min_items: 1` | `"type":"array"`, `"minItems":1`, `"items":{"type":"string"}` | `json["tags"].as_a.map(&.as_s)` | `Array(String)` |
| `array :items, of: Item, optional: true` | `"items":` + `Item.schema_json` (runtime `j.raw Item.schema_json`) | `json["items"]?.try(&.as_a.map { \|v\| Item.from_json(v.to_json) })` | `Array(NamedTuple(...))?` |
| `object :addr, of: Address` | `j.raw Address.schema_json` | `Address.from_json(json["addr"].to_json)` | `NamedTuple(...)` |
| `object :addr, of: Address, optional: true` | aynı | `json["addr"]?.try { \|v\| Address.from_json(v.to_json) }` | `NamedTuple(...)?` |

**Not:** `array`'in `of:`'u ya `:symbol` ya da bir schema tipi (Path) olabilir — makroda ikisini ayır: `expr.named_args["of"].is_a?(SymbolLiteral)` vs Path.

### 3.3 Kısıt eşlemesi (makroda named_args okuma)

| named arg | Schema keyword |
|---|---|
| `min:` | `minLength` (string) |
| `max:` | `maxLength` (string) |
| `pattern:` | `pattern` |
| `format:` | `format` |
| `values:` | `enum` |
| `gt:` | `exclusiveMinimum` |
| `lt:` | `exclusiveMaximum` |
| `gte:` | `minimum` |
| `lte:` | `maximum` |
| `min_items:` / `max_items:` | `minItems` / `maxItems` |
| `optional: true` | `required` listesine ekleme |

`enum` adını **parametre adı olarak kullanamazsın** (Crystal keyword) — `values:` zaten bu yüzden böyle.

### 3.4 Yapılmaması gereken tuzak

**Compile-time JSON string üretme** (`SCHEMA_JSON = "{\"type\":...}"` gibi makro içinde string birleştirme). Pattern/format gibi değerlerde JSON escaping compile-time'da yanlış çıkar. Bunun yerine **3.1'deki gibi runtime `JSON.build`** — `@@schema_json ||=` ile memoize. Tek kurulum maliyeti, sonra sabit.

## 4. Adım 2 — `yozgat-crystal`: `env.status/text/json` helper'ları

`src/lib/env_ext.cr` (yeni dosya):

```crystal
class HTTP::Server::Context
  # env.status(404).text("...") — zincir için self döner
  def status(code : Int32) : self
    response.status_code = code
    self
  end

  def text(content : String) : String
    response.content_type = "text/plain"
    content
  end

  def json(content) : String
    response.content_type = "application/json"
    content.to_json
  end
end
```

**Kritik:** bu metotlar **String döndürüyor** (Kemal, route bloğunun dönüş değerini yazar). `env.response.print` ile karıştırma — `print` + dönüş değeri birlikte olursa "already wrote response" hataları çıkar.

## 5. Adım 3 — `yozgat-crystal`: `api` makrosu

`src/lib/api_macro.cr` (yeni dosya):

```crystal
macro api(method, path, *, body = nil, query = nil,
          summary = nil, tags = [] of String, security = [] of String,
          responses = {} of String => String, &handler)
  {{method.id}} {{path}} do |env|
    {% if body %}
      raw = env.request.body.try(&.gets_to_end) || "{}"
      res = {{body}}.validate(raw)
      unless res.valid
        payload = {error: "validation_error", details: res.errors}.to_json
        halt env, status_code: 422, response: payload
      end
      body = {{body}}.from_json(raw)          # NamedTuple → body.title
    {% end %}

    {% if query %}
      qjson = Yozgat::Query.params_to_json(env.params.query)   # bkz. Adım 4
      res = {{query}}.validate(qjson)
      unless res.valid
        payload = {error: "validation_error", details: res.errors}.to_json
        halt env, status_code: 422, response: payload
      end
      query = {{query}}.from_json(qjson)
    {% end %}

    {{handler.body}}
  end

  # OpenAPI kaydı — top-level, program açılışında çalışır
  Yozgat::OpenApi.register(
    method: {{method.stringify}},
    path: {{path.stringify}},
    summary: {{summary.stringify}},
    tags: {{tags}},
    security: {{security}},
    responses: {
      {% for code, schema in responses %}
        {{code}}.to_s => {{schema}}.schema_json,
      {% end %}
    })
end
```

**Dikkat noktaları:**

- **`res.errors.to_json`** — `ValidationError` struct'ı şu an `JSON::Serializable` değil. Ya `validator.cr`'da `include JSON::Serializable` ekle, ya da makroda hash'e çevir: `res.errors.map { |e| {path: e.path, message: e.message} }`. (Plan: hash'e çevir — paket değişikliği gerektirmez.)
- **`responses` macro HashLiteral'dır** — `{% for code, schema in responses %}` ile compile-time dolaşılır; `code` NumberLiteral ise `{{code}}.to_s` → `"201"`.
- **`{{handler.body}}` splice** — handler kapsayıcı scope'taki **local değişkenleri göremez** (method'a taşınmaz, direkt route bloğuna girer; `env`, `body`, `query` zaten tanımlı). Ama bloğun üstündeki `TaskSchema` gibi **constant'ları görür**.
- **`halt` validasyondan sonra erken çıkış** — handler'a asla geçilmez.

## 6. Adım 4 — Query handling (v1)

`src/lib/query.cr`:

```crystal
module Yozgat
  module Query
    # env.params.query → JSON string. Değerler string kalır.
    def self.params_to_json(params : HTTP::Params) : String
      params.to_h.to_json
    end
  end
end
```

**V1 yaklaşımı (tavsiye):** query şemaları string + pattern kullanır. `?name=murat` direkt string. Sayı gerekirse handler çevirir:

```crystal
PageQuery = Ata.object do
  string :name, min: 1
  string :page, pattern: "\\d+", optional: true
end

api :get, "/hello", query: PageQuery do
  page = query.page.to_i   # pattern doğruladığı için güvenli
  env.text("Hello #{query.name} (page #{page})")
end
```

**Neden coercion yok:** `?page=1` string "1" gelir; runtime coerce yaparsan `string :page, pattern: "\\d+"` şemasıyla uyumsuzlaşır (coerce "1" → int 1, şema string ister). İki tutarlı dünya:
- **(a) Hep string:** şema string/pattern, handler `.to_i`. Basit, öngörülebilir. **V1 bu.**
- **(b) Compile-time typed coerce (ileride):** makro, alan tipini bildiği için `page: raw["page"].to_i` üretebilir — runtime magic yok. Ama bu, şema validasyonunu "coerce sonrası" yapmayı gerektirir (string şema coerce sonrası değere uymaz). Karmaşık; v1'e alma.

## 7. Adım 5 — `yozgat-crystal`: OpenApi ince katmanı

`src/lib/open_api.cr`:

```crystal
module Yozgat
  module OpenApi
    class Operation
      getter method : String, path : String, summary : String?,
              tags : Array(String), security : Array(String),
              responses : Hash(String, String)

      def initialize(@method, @path, @summary, @tags, @security, @responses); end
    end

    @@operations = [] of Operation
    @@title : String?
    @@version : String?
    @@servers : Array(String) = [] of String

    def self.register(method : String, path : String, summary : String?,
                      tags : Array(String), security : Array(String),
                      responses : Hash(String, String)) : Nil
      @@operations << Operation.new(method, path, summary, tags, security, responses)
    end

    def self.setup(title : String, version : String, servers : Array(String) = [] of String) : Nil
      @@title = title
      @@version = version
      @@servers = servers

      # /openapi.json
      get "/openapi.json" do |env|
        env.response.content_type = "application/json"
        spec_json
      end

      # /docs → Swagger UI (statik HTML, CDN'den)
      get "/docs" do |env|
        env.response.content_type = "text/html"
        swagger_html
      end
    end

    def self.spec_json : String
      String.build do |io|
        JSON.build(io) do |json|
          json.object do
            json.field "openapi", "3.1.0"
            json.field "info" do
              json.object do
                json.field "title", @@title.not_nil!
                json.field "version", @@version.not_nil!
              end
            end
            unless @@servers.empty?
              json.field "servers" do
                json.array do
                  @@servers.each { |u| json.object { json.field "url", u } }
                end
              end
            end
            json.field "components" do
              json.object do
                json.field "securitySchemes" do
                  json.object do
                    json.field "bearer_auth" do
                      json.object do
                        json.field "type", "http"
                        json.field "scheme", "bearer"
                      end
                    end
                  end
                end
              end
            end
            json.field "paths" do
              json.object do
                @@operations.group_by(&.path).each do |path, ops|
                  json.field path do
                    json.object do
                      ops.each do |op|
                        json.field op.method do
                          json.object do
                            json.field "summary", op.summary if op.summary
                            json.field "tags", op.tags unless op.tags.empty?
                            unless op.security.empty?
                              json.field "security" do
                                json.array do
                                  op.security.each do |s|
                                    json.object { json.field s, [] of String }
                                  end
                                end
                              end
                            end
                            json.field "responses" do
                              json.object do
                                op.responses.each do |code, schema_json|
                                  json.field code do
                                    json.object do
                                      json.field "description", "HTTP #{code}"
                                      json.field "content" do
                                        json.object do
                                          json.field "application/json" do
                                            json.object do
                                              json.field "schema", JSON.parse(schema_json)
                                            end
                                          end
                                        end
                                      end
                                    end
                                  end
                                end
                              end
                            end
                          end
                        end
                      end
                    end
                  end
                end
              end
            end
          end
        end
      end
    end

    def self.swagger_html : String
      # swagger-ui-dist CDN HTML — `/docs`
    end
  end
end
```

**Dikkatler:**

- `responses`'ta body şeması da isteniyorsa: `register`'a `body : String?` alanı ekle (`{{body}}.schema_json` veya nil), spec'te `requestBody.content.application/json.schema` olarak bas.
- `json.field "schema", JSON.parse(schema_json)` — JSON::Any içine gömmek için parse edip göm. (JSON::Builder bir JSON string'i `raw` ile de gömer; `schema_json` zaten geçerli JSON, `json.field "schema"` yerine `j.raw` kullanımı da olur — hangisi rahatsa.)
- **`setup` çağrısı** `main.cr`'da `Kemal.run`'dan önce:
  ```crystal
  Yozgat::OpenApi.setup(title: "Yozgat API", version: "1.0.0",
    servers: ["http://localhost:3000"])
  ```
- **OpenAPI 3.1** çıktısı — `exclusiveMinimum: 0` sorunsuz.

## 8. Adım 6 — Mevcut route'ları `api` makrosuna geçir

`src/api/hello.cr`:

```crystal
HelloQuery = Ata.object do
  string :name, min: 1
end

api :get, "/hello", query: HelloQuery, summary: "Greets a user", tags: ["hello"] do
  env.text("Hello #{query.name}")

```

`src/api/auth.cr` migration notları:
- `get "/setup-status" do ... end` → `api :get, "/setup-status" ... do ... end` (schema yok, sadece handler).
- `post "/auth/register"` → body şeması ekle:
  ```crystal
  RegisterBody = Ata.object do
    string :email, format: "email"
    string :password, min: 8
    string :verify_password, min: 8   # hmm, key adı; JSON'da verifyPassword? → alan adı Symbol; DSL şu an ASCII key üretir. camelCase alan istersen DSL'e "json key" desteği gerekebilir!
  end
  ```
  **Bu bir eksiklik:** `string :verifyPassword` — Crystal'da Symbol `:verifyPassword` geçerli. Sorun yok; alan adı olarak `"verifyPassword"` üretilir. Ama `body.verifyPassword` method çağrısı olarak NamedTuple alanına erişimde `body[:verifyPassword]` kullanılır (dot erişim camelCase'te çalışır: `body.verifyPassword` da geçerli, NamedTuple alanı).
- `me(env)` gibi handler'lar `env.status(401).json(...)` desenine çevrilir; `Yozgat::API::Auth` metodları korunur (env + dönüş String).
- `security: ["bearer_auth"]` sadece OpenAPI dokümantasyonu için; **gerçek koruma handler içindeki `Yozgat::Auth.authenticated(env)` çağrısı** olmaya devam eder (makro security'yi çalıştırmaz — sadece spec'e yazar). İstersen makroya `auth: true` parametresi eklenip `claims = Yozgat::Auth.authenticated(env)` otomatik üretilebilir (ileride).

## 9. Adım 7 — Spec'ler

`ata-validator-crystal/spec/dsl_spec.cr` (uyum kontrolü):
- `User.valid?(...)`, `User.schema_json` — makro sonrası class method'lar, **değişmeden geçmeli**.
- `Ata.object` top-level constant — makro tip alias'ı olur, spec dosyasında top-level `User = Ata.object do ... end` zaten var.
- **Yeni spec:** `User.from_json(%({"title":...}))` → NamedTuple tip kontrolü. Tip ataması: `x = User.from_json(...)`, `typeof(x)` ile NamedTuple olduğunu doğrula.
- **Yeni spec:** nested — `Person = Ata.object do ... object :address, of: Address end` → `typeof(Person.from_json(...))`.

`yozgat-crystal/spec/`:
- `OpenApi.spec_json` yapısı: paths → `/hello` → `get` → responses → schema mevcut.
- `api` makrosu: gerçek Kemal server kaldırmak yerine, route'un kayıtlı olduğunu doğrulamak için spec'te `HTTP::Server::Context`'e mock etmek zor. **Pratik:** entegrasyon testini elle (server aç, curl) yap; spec'te sadece `OpenApi` + şema struct'larını test et.

## 10. Hatalı olanlar / bilinen tuzaklar (özet)

1. **`yozgat-crystal` şu an `Ata.object`'i çözemez** — GitHub'daki 0.1.1 DSL'siz. (Yerel `dsl.cr` hiç push edilmedi.) → Adım 11.
2. **`Ata.object` runtime method** — `body.title` için makroya şart. Bu tek büyük değişiklik.
3. **`with builder yield`** — makroya geçince ortadan kalkar (blok runtime'da çalışmaz). Mevcut DSL'de anonim blok zorunluluğu da gider.
4. **`enum` parametre adı** — `values:` (zaten çözüldü, makroda da koru).
5. **`JSON::Builder#raw` object bağlamında** — eski Builder'da yaşadık; makroda `j.raw <schema>.schema_json` yalnızca **değer bağlamında** kullanılmalı (nested object/array items). `properties` object'inin içinde değil — orada `j.field name do ... end` bloğu.
6. **Compile-time JSON escaping** — yapma. Runtime `JSON.build` + memoize.
7. **`ValidationError` JSON'a çevrilemez** (JSON::Serializable yok) — makro hash'e çevirir.
8. **Kemal 1.6.0** — `kemal-openapi` shard'ı 1.11 ister. Kendi katmanın bu yüzden.
9. **Handler scope** — `{{handler.body}}` kapsayıcı local'leri görmez (constant görür).
10. **`responses` macro HashLiteral** — `{} of String => String` default'u makro parametresinde geçerli; iterasyon compile-time.
11. **Query string coerce** — v1'de yok; string/pattern. Magic coerce ileride, ayrı karar.
